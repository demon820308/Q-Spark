# Q-Spark v0.2.1 Release Notes

## ⚡ Q-Spark v0.2.1 - 全能创作工作台与全功能历史画廊 (All-in-One Studio & History Gallery 2.0)

Q-Spark v0.2.1 带来了重磅升级：在单一交互工作台内全面打通了**文生图 (txt2img)**、**图生图 (img2img)** 与**图像编辑/局部重绘 (Inpainting)**，实现创作流程一站式流转闭环；同时上线多 LoRA 动态挂载与全功能沉浸式历史画廊 2.0。

---

### 🚀 核心新特性 (What's New)

#### 1. 🎨 单一工作台三态合一 (All-in-One Studio)
- **文生图 (txt2img)**：零底图直接生图，支持极速 6~8 步推理、CFG 与随机种子调节。
- **图生图 (img2img)**：支持底图上传、拖拽与剪贴板一键 Ctrl+V 粘贴，提供 0.10 ~ 1.00 重绘幅度（Strength）平滑控制，一键自动匹配底图宽高比。
- **图像编辑 / 局部重绘 (Inpainting)**：
  - 纯原生 HTML5 Canvas 涂抹工作台（零第三方图形库依赖）；
  - 画笔模式、橡皮擦模式、5px ~ 150px 粗细实时滑块调节、一键清空；
  - 提供“🔄 反转蒙版（重绘背景保留主体）”选项，换背景高频需求一键搞定；
  - 自动映射图片物理自然分辨率，导出严格 1:1 黑白二值 PNG 蒙版（纯黑保留，纯白重绘），通过 `sd-cli --mask` 实现精准局部修复。

#### 2. 🏷️ 多 LoRA 动态挂载机制 (LoRA Dynamic Mounting)
- 自动扫描识别 `models/loras/` 下的 safetensors 权重；
- 下拉选择与即时挂载，每个 LoRA 独立调节权重（0.1 ~ 2.0），自动展开提示词宏并传参至底层 CLI。

#### 3. 🖼️ 全功能沉浸式历史画廊 2.0 (History Gallery & Lightbox)
- **Sidecar JSON 完整元数据持久化**：每张图片生成均附带独立伴生 JSON，完整记录提示词、负面词、模型组合、LoRA 列表、步数、CFG、耗时与模式标记；
- **全流程一键闭环**：
  - `⚡ 参数重绘 / 复用`：一键将历史参数回填至表单；
  - `🔄 垫图`：一键送入图生图作为底图；
  - `🖌️ 重绘`：一键调取底图并打开涂抹画布，直接局部重绘；
- **方案 A 沉浸式全屏原图查看器**：支持原图 1:1 物理像素与适应屏幕双态缩放切换，支持 ESC 键与遮罩一键关闭。

#### 4. 🧠 硬件监控与显存管理
- 毫秒级采集 GPU 显存 (VRAM)、系统内存 (RAM) 与 CPU 占用率，提供动态色条状态预警；
- 三种显存管理策略：即用即走（On-Demand，闲置 0MB 显存）、智能休眠（Auto-Unload）、显存常驻（Always-On）。

---

### 📦 便携版特性 (Portable Highlights)
- **零依赖开箱即用**：内置轻量独立 Python 3.12 绿色运行时与所有依赖，无需在系统中安装 Python；
- **完整 CUDA 12 加速推理**：内置纯 C++ 编译的 `sd-cli.exe` 与 CUDA 运行时加速库；
- **原生启动器**：解压后双击 `start.bat` 或 `Q-Spark.exe` 即可直接起飞！

---

### 🛠️ 升级与快速上手 (Quick Start)
1. 下载 `Q-Spark-0.2.1-windows-x64-portable.zip` 并解压；
2. 将下载好的模型放入 `models/` 对应子目录（或在网页设置中指向已有的 ComfyUI/models 目录）；
3. 双击 `start.bat` 即可启动，浏览器自动打开 `http://127.0.0.1:40188`。
